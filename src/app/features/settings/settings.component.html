 Security & Privacy Zero-Knowledge, Offline Architecture

• Local Database: SQLite encrypted with SQLCipher (AES-256).

• Key Derivation: Argon2id (64 MiB memory, 3 passes, 16-byte random salt).

• Key Hierarchy: 256-bit DEK wrapped via AES-256-GCM.

• Biometrics: Real Android Keystore hardware-backed encryption key.

• Screen Security: Android FLAG_SECURE blocks screenshots and task switcher previews.

• Strictly Offline: No network permissions, zero telemetry, zero servers.
